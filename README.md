# ShebaSathi Backend

ShebaSathi Backend is the API server for the ShebaSathi healthcare support platform.

ShebaSathi helps rural families, patients, elderly people, and expatriates arrange medical support in Dhaka, including doctor appointments, transport, accommodation, and related coordination services.

## Main Purpose

This backend powers:

- User registration and login
- JWT authentication
- Doctor appointment booking
- Hotel / accommodation booking
- Transport / ambulance booking
- User dashboard data
- Admin dashboard management
- Booking status updates
- Doctor management
- Hotel management
- Fare management
- OTP login structure

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- CORS
- dotenv
